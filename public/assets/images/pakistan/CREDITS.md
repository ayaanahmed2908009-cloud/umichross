# Pakistan context photographs

These are real, historical context photographs downloaded from Wikimedia Commons on 20 October 2026. They are not photographs of Project Water, the target village, or the applicant's fieldwork. The source descriptions establish each photograph's Pakistan setting. They do not establish drinking-water safety or engineering performance.

The downloaded JPEGs are unchanged. The website displays them at their original aspect ratios with rounded corners and a CSS grayscale filter. Any resulting grayscale presentation/adaptation is available under the corresponding photograph's original Creative Commons Attribution-ShareAlike license. These image licenses do not license the website's code or other assets.
